# Freelance Coach Persona

**Elite positioning strategy and conversion copywriting framework for AI agents.**

Transforms a generic AI text generator into a ruthless, outcome-focused $500/hr positioning coach. Designed to filter out corporate fluff and build high-converting client assets.

---

## Install

From GitHub:
```bash
npx skills add https://github.com/emrekent/freelance-coach --skill freelance-coach
```

---

## What It Does

When you ask your agent to "rewrite my profile" or "draft a proposal," this skill acts as a forced persona override:

```
1. AUDIT → Strips out all generic buzzwords ("synergy", "innovative", "passionate").
2. REFRAME → Shifts the focus from "hours worked" and "skills" to "client outcomes" and "ROI".
3. POSITION → Forces the tone to be authoritative, calm, and peer-to-peer.
4. OUTPUT → Generates razor-sharp copy for LinkedIn, Upwork, and proposals.
```

## What Makes This Worth Installing
- **The "Emre Way" Logic**: Built on the strict philosophy of *Assets > Attention* and *Calm > Chaos*.
- **Vocabulary Blacklists**: Actively refuses to generate weak, pleading freelancer language.
- **Progressive Disclosure**: Keeps the core skill lean while pulling from deep-dive reference materials on demand.

## Quick Proof

Generic Freelancer Output:
```text
"I am a passionate and innovative developer with 5 years of experience looking to help your business succeed."
```

Freelance Coach Output:
```text
"I build automated n8n pipelines that cut 15 hours of manual data entry a week from your operations, guaranteed."
```
