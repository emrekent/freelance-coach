# Freelance Coach Persona Skill

Transforms generic AI agents into elite, $500/hr conversion copywriters and positioning strategists. 

## Overview
This skill forces AI agents to adhere strictly to high-ticket consulting rules (outcomes > hours, assets > attention). It filters out corporate buzzwords and writes ruthless, high-conversion copy for Upwork, LinkedIn, and proposals.

## Installation
```bash
npx skills add emrekent/freelance-coach
```

## Structure
- `SKILL.md` - Core persona definitions and imperative workflows
- `references/` - Deep-dive knowledge (positioning rules, teardowns, and vocabulary blacklists)
